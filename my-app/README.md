# 烟花产品目录 · 浅色双语版

## 替换文件
1. 将 `src` 内的文件合并覆盖到现有 Vite React 项目的 `src`。
2. 将 `public/favicon.svg` 放到项目的 `public` 文件夹。
3. 用本包的 `index.html` 替换项目根目录的同名文件（不要放入 src）。
4. 保留现有 package.json、Vite 配置；无需安装额外依赖。运行 `npm run dev`。

顾客页面：http://localhost:5173/
管理页面：http://localhost:5173/#admin
若 Vite 使用其他端口，以终端地址为准。

## 本次更新
- 全站浅色主题，包括顾客页、管理页和视频弹窗。
- 默认简体中文；页面右上角支持中文 / EN 切换并记住选择。HTML lang 与浏览器标题同步切换。
- 产品、分类、系列可填写英文名称；留空则显示原名称。已有示例名称可自动中英切换，自定义名称不会自动机器翻译。
- 手机宽度不超过 767px 时隐藏首页 banner，直接显示分类与产品；产品保持双列，分类可横向滑动。管理表格在手机上转为卡片。
- 页脚可显示电话、WhatsApp、邮箱、地址和营业时间。进入管理页 → 设置 → 联系资料填写；未填写的项目不显示，没有预设真实号码。
- 内置烟花 SVG 标签图标与中文标签标题。设置中可替换标签图标链接、自定义中英标题、商店 Logo、名称和宣传语。标题留空时按商店名称及界面语言自动生成。
- 保留旧版本 localStorage 键和全部现有产品；新设置字段自动补齐，不会清空旧资料。

## 功能与限制
包含分类/系列新增、编辑、排序和删除，产品新增、编辑、隐藏和删除，搜索，页面内视频播放，Logo 设置，JSON 导入导出。视频支持 YouTube 和 MP4/WebM/OGG 直链；视频所有者可能禁止嵌入，可使用“打开视频”。示例产品仍需自行添加视频。

这是前端本地演示：资料仅保存在当前浏览器/网站来源，不会跨设备共享。#admin 没有权限保护。正式上线仍须接入共享数据库及服务器端管理权限验证。不要在 React 或 VITE_ 环境变量中放入管理员密钥。

导入备份会在确认后替换当前浏览器目录。删除有产品/系列的分类会被阻止；删除系列保留产品。清除浏览器资料前请导出备份。

## 分页与上传更新
- 管理页和顾客页默认每页 8 款，可切换 8 / 16 / 32，并可选择页码、上一页、下一页。搜索、分类、系列筛选均在分页之前进行，切换筛选自动返回第一页。
- 顾客页使用紧凑卡片；桌面四列、手机两列，桌面横幅缩为一条，手机继续隐藏。以 1366×768 桌面和 390×844 手机为参考，可同时看到搜索栏与首屏 8 款。更小屏幕或浏览器放大时可能需滚动。
- 新增产品仅名称必填。分类、系列、视频和图片都可留空；无分类产品显示“未分类”。只有图片时，点击卡片展示大图；无媒体时显示产品名称与联系提示。
- 支持上传 JPG/PNG/WebP/GIF（最大 10 MB）及 MP4（最大 100 MB），或继续使用链接。上传文件后可移除并改用链接，保存前取消不会产生永久上传文件。
- 上传媒体存入 IndexedDB；资料继续存入 localStorage，刷新后保留。浏览器空间不足时会提示保存失败。清理网站资料会删除这些内容。
- JSON 备份仅含产品资料、链接和本地媒体编号，不含上传文件。在另一设备导入后，需重新上传原始媒体文件。因此请自行保留原始图片/视频；文件没有上传至共享服务器。
